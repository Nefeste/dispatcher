# Диспетчер 03

Смена диспетчера скорой помощи в большом городе — игра на телефон для RuStore студии «Горница». Звонит человек, вы
расспрашиваете его, решаете, насколько вызов срочный, и отправляете бригаду. Бригады едут по настоящим улицам, вызовы
копятся. После смены — разбор: где вы ошиблись со срочностью и чего это стоило. Медицина — из той же модели с
названными источниками, что и в «Анамнезе».

Это игра, а не обучение. Если нужна помощь — звоните 103 или 112.

Где проект сейчас — [`STATUS.md`](STATUS.md).

## Как запустить

```bash
npm ci
npx expo start                     # сервер разработки; «w» — открыть в браузере
npm run typecheck && npm run lint && bun test tools/test
npm run export:web && NODE_PATH=/opt/node22/lib/node_modules bun tools/e2e/browser.ts   # сценарий в браузере
python blender/build.py            # модель рабочего места: Blender 4.5.15 модулем Python (pip install bpy==4.5.15)
python blender/pult.py             # кадр стола для сцены «Пульт»
bun tools/people/fetch.ts <папка> && python blender/caller.py <папка>   # люди Rocketbox → картинка звонящего
python blender/insert.py           # видеовставка «бригада выезжает» (нужен ffmpeg)
```

Что проверять перед каждым push — [`docs/06-testing.md`](docs/06-testing.md); процесс и версии —
[`docs/05-process.md`](docs/05-process.md).

## Версии

### 0.10.0 — сборка для телефона и «Замер»

Игру можно поставить на телефон: тег версии собирает APK, подписанный постоянным ключом, и кладёт его на страницу
выпуска. Сети в нём нет — игра работает целиком на телефоне; разрешений — только режим звука. У игры свой значок:
«03» на кумаче. На заглавном экране — «Замер»: игра сама двигает и приближает карту, ведёт смену на пульте с
бригадами в пути, ищет пути по району и пишет, сколько кадров в секунду, сколько долгих кадров, сколько занял поиск,
сколько памяти и сколько шёл запуск — итог можно отправить.

### 0.9.0 — обёртка: от заглавного экрана до снимка смены

Смена теперь начинается с загрузки с настоящим ходом полосы и короткого ролика: двор подстанции вечером, машина у
гаража. Поверх карты — три строки о том, что делать; часы стоят, пока их не закрыли. Первые три звонка — учебные, с
подсказками по шагам: дочь, у которой отец не отвечает, — спросить о дыхании, экстренная, ближайшая бригада; сам
больной с температурой — неотложная; прохожий у остановки, который ничего не знает о болезнях, — что спросить, чтобы
решить. Новый звонок звенит и коротко отзывается вибрацией, строка бригады по рации щёлкает; к 19:00 карта темнеет.
У звонящих-мужчин своя картинка. В итоге — время игры и лучший итог этой смены, а «Снимок смены» сохраняет карту
района с путями всех бригад и тремя числами — картинкой для себя. В настройках — автопауза, звук, вибрация и «Меньше
движения».

### 0.8.0 — разбор смены

После смены — разбор. Сверху три числа и главная ошибка смены: самая дорогая в минутах, с переходом к её вызову.
Ниже — все вызовы: какую форму решили и какой она была на самом деле, вовремя ли приехала бригада. У вызова —
разговор целиком и две оценки, не смешанные. «По известному» — верно ли решено по тому, что звонящий успел сказать:
не решили ли против услышанного, не пропустили ли вопрос, который всё бы изменил, не обогнал ли неотложный вызов
экстренный. Если звонящий просто не знал, разбор так и пишет: это не ошибка. «По правде» — что было с человеком и
успела ли помощь: норма доезда, окно лечения, та ли больница. «Ещё раз» — та же смена с новыми звонками. Смене
прибавилась шестая бригада, а звонящие стали говорить смутнее: угрозу чаще открывают вопросы.

### 0.7.0 — смена: от первого звонка до конца

«Начать смену» открывает настоящую смену: вечер буднего дня, с 17:00 до 19:00, пять бригад на двух подстанциях, три
больницы. Сначала три учебных звонка, потом звонки идут сами, около двадцати за смену. Звонок ставит мир на паузу;
телефон его принимает. В разговоре — вопросы по вкладкам: каждый стоит игровых секунд, ответ ложится в карточку
вызова, переспросить дешевле. Решение — форма вызова, потом кого послать: список бригад со временем доезда, едущую на
неотложный можно развернуть на экстренный; или «оставить ждать» — вызов встанет под картой, и его можно отдать бригаде
касанием. Кто долго ждёт — перезванивает. Бригада на месте докладывает, что нашла, и спрашивает, куда везти: больницы
со временем дороги и профилями; не ответили за две минуты — повезут в ту, что предложила бригада. Смена кончается,
когда доведён последний вызов, — итог в три числа. Смену можно закрыть и продолжить с той же секунды. Разбор вызовов —
следующая часть.

### 0.6.0 — медицина: кто звонит и что он знает

Внутри игры появились больные. Каждый звонок рождает человека из медицинской модели «Анамнеза» с одной из двенадцати
болезней прототипа — от инсульта до боли в спине, — с возрастом, сопутствующими болезнями и признаками, у каждого из
которых есть причина. Звонит сам больной, родственник, сосед или прохожий, и каждый знает своё: прохожий не знает
болезней, родственник не всегда знает, когда началось. Первые слова не всегда говорят главное — угрозу жизни чаще
открывают вопросы. Звонящий не врёт: не знает — так и говорит. Двадцать вопросов в шести группах, форма вызова — по
порядку оказания скорой помощи. Всё медицинское — черновик с источниками, пока его не проверит человек. На экране пока
прежний пробный разговор: смена с этими звонками — следующая часть.

### 0.5.0 — бригады едут по улицам

На карте пульта появились две подстанции, три больницы и пять бригад. Часы смены идут: касание часов — пауза, касание
скорости — ×1, ×2, ×4. После решения в разговоре на вызов едет ближайшая свободная бригада — по настоящим улицам, с
путём на карте; доехав, она говорит по рации «на месте», отработав — возвращается. Подстанции и больницы вымышленные.

### 0.4.0 — сцены: пульт, звонящий, бригада выезжает

Игра становится сценами, а не экранами с кнопками. «Пульт» на первом экране открывает смену так, как её видит
диспетчер: монитор с картой района почти на весь экран, над картой — часы смены и линия, под ней — вызовы, ждущие
бригаду; внизу — край стола с телефоном и рацией. Телефон принимает звонок: сверху — дочь, которая звонит из
квартиры матери, ниже — опросник на мониторе: вопросы заполняют карточку вызова, решение — форма вызова. После
решения — короткий ролик: машина скорой выезжает из гаража подстанции. Это эталонные кадры: смены пока нет.

### 0.3.0 — рабочее место диспетчера

С первого экрана, «Рабочее место», открывается зал диспетчерской вечером: стол с двумя мониторами — на одном карточка
вызова, на другом карта района с бригадами, — гарнитура, телефон, рация, селектор; за перегородкой — соседние места и
видеостена с картой и табло загрузки. Проведите пальцем — оглядеться. Что стоит на столе, взято из стандарта оснащения
и описаний настоящих диспетчерских. Это проба вида: смены по-прежнему нет.

### 0.2.0 — карта района

Карта района Нижнего Новгорода — Нагорная часть у Стрелки и Канавино за Окой, около 6 × 9 км: улицы, Ока и Волга,
мосты, железная дорога, парки — из OpenStreetMap. Карту можно сдвигать одним пальцем и приближать двумя; открыть её
пока можно с первого экрана, «Карта района». Под ней — граф дорог и поиск пути для будущих бригад.

### 0.1.0 — каркас прототипа

Первый экран с названием и строкой «Это игра. Если нужна помощь — звоните 103 или 112.», экран «Об игре» с
указанием OpenStreetMap и источников медицины. Смены ещё нет: кнопка «Начать смену» видна, но не нажимается. Шрифты
и цвета студии, своё окно подтверждения вместо системного, настройки на телефоне. Не выпускается: сборки для телефона
появятся в конце прототипа.
