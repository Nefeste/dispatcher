# Диспетчер 03

Смена диспетчера скорой помощи в большом городе — игра на телефон для RuStore студии «Горница». Звонит человек, вы
расспрашиваете его, решаете, насколько вызов срочный, и отправляете бригаду. Бригады едут по настоящим улицам, вызовы
копятся. После смены — разбор: где вы ошиблись со срочностью и чего это стоило. Медицина — из той же модели с
названными источниками, что и в «Анамнезе».

Это игра, а не обучение. Если нужна помощь — звоните 103 или 112.

Где проект сейчас — [`STATUS.md`](STATUS.md).
