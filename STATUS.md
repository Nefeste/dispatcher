# Состояние «Диспетчера 03»

**Версия:** 0.3.0 — рабочее место диспетчера: сцена Three.js из Blender, экраны на Skia (проба вида); смены ещё нет.

**Этап:** 1 — прототип ([`docs/specs/2026-11-prototype.md`](docs/specs/2026-11-prototype.md)), начат 19.11.2026 по
решению владельца: «продолжай планирование разработки или приступай к прототипу, если фаза планирования завершена». Планирование закончено: спецификация слита 18.11.2026
([#2](https://github.com/Nefeste/dispatcher/pull/2)), город — Нижний Новгород
([#1](https://github.com/Nefeste/dispatcher/issues/1)). Репозиторий открыт до 1.0.0 (ADR
[0008](docs/adr/0008-open-until-1.0.md)).

**Что дальше:** части прототипа по порядку — [`docs/07-roadmap.md`](docs/07-roadmap.md), «Прототип — по частям».
П1, П2 и рабочее место слиты. Стек решён: игра из сцен на Expo и Skia (ADR [0009](docs/adr/0009-scenes.md)).
Следом — эталонные кадры сцен (пульт, звонящий, вставка), П3 — бригады едут по улицам, П4 — медицина.

**Ждёт владельца:**

- секрет `AUTOMERGE_TOKEN` в настройках репозитория — для автослияния по метке «ревью: ок», как в других играх;
- название по ФИПС — по решению 15.11.2026 до спецификаций, ещё не сделано; до выпуска — деньги, возрастная
  категория.
