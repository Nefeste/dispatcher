# Данные

Что лежит в содержании, в состоянии смены и в сохранении. Как это устроено в коде — [`02-architecture.md`](02-architecture.md),
откуда факты — [`09-content.md`](09-content.md).

## 1. Содержание (`content/`)

YAML, одна запись — один файл, идентификатор — из пути, вечный
([правило устава](https://github.com/Nefeste/gornitsa/blob/main/docs/05-rules.md#код)). Сборка —
`tools/content/build.ts` → `src/content/generated/` (не в git), как в «Анамнезе».

| Папка | Запись | Что в ней |
|---|---|---|
| `med/` | копии «Анамнеза» | болезни (`cond.*`), признаки, факторы риска — байт в байт; перечень `med/FROM.yaml`: идентификатор, коммит «Анамнеза», SHA-256 |
| `phone/findings/` | признак по телефону | кто из звонящих может сказать о признаке и насколько уверенно; слова звонящего; признак угрозы жизни |
| `phone/conditions/` | болезнь по телефону | повод, форма вызова, нужная бригада, профиль больницы, время на месте, окно |
| `reasons/` | повод | первые слова звонящего («упал и не встаёт») и группа поводов по порядку скорой помощи |
| `questions/` | вопрос диспетчера | слова вопроса, цена в игровых секундах, какие признаки или сведения он открывает |
| `callers/` | звонящий | кем приходится больному, что знает (болезни, жалобы, видимое), как отвечает |
| `crews/` | вид бригады | состав, что умеет, с какими поводами её посылают |
| `cities/` | город | файл карты, район смены, подстанции, больницы с профилями |
| `shifts/` | смена | город, район, начало и длина, бригады по подстанциям, поток, учебные звонки |
| `roads.yaml` | дороги | скорость по классу дороги и множитель по часу суток — числа баланса |
| `flow.yaml` | поток | доля звонков по часам суток — число баланса |

### Признак по телефону — `phone/findings/<id>.yaml`

```yaml
id: sym.chest_pain            # тот же, что в content/med/
tell:                         # насколько вероятно, что звонящий знает и скажет (полосы «Анамнеза»)
  self: always                # сам больной
  relative: usually           # родственник рядом
  neighbour: often
  bystander: sometimes        # прохожий видит только видимое
ask: [q.pain_where]           # вопросы, которые его открывают; без вопроса — только если salience ≥ 2
says:
  present: ["Говорит, давит за грудиной"]
  absent: ["Нет, на грудь не жалуется"]
  unsure: ["Не знаю, он не говорит"]
threat: false                 # признак угрозы жизни — по перечню поводов экстренной формы, с источником
sources: [...]
review: draft
```

### Болезнь по телефону — `phone/conditions/<id>.yaml`

```yaml
id: cond.stroke_ischemic
reason: reason.face_speech    # с чем звонят чаще всего; другие поводы — из признаков
form: emergency               # по порядку оказания скорой помощи — с источником
crew: crew.general            # какая бригада нужна; меньшая — ошибка, большая — занятая зря
hospital: profile.stroke      # куда везти; none — помощь на месте
scene: [15, 30]               # минут на месте — число баланса, «оценка»
transport: 0.95               # доля, кого везут в больницу
window:                       # после какого срока опоздание меняет исход — только из источника
  minutes: 270                # пример формата, не факт: число — из клинических рекомендаций, с их ID
  from: onset                 # от начала болезни или от звонка (call)
sources: [...]
review: draft
```

### Город — `cities/<id>.yaml`

```yaml
id: city.proto
map: assets/map/proto.bin     # с паспортом assets/map/proto.json
district: { name: "…", box: [x0, y0, x1, y1] }  # см в местной проекции
bases:                        # подстанции — вымышленные имена и места
  - { id: base.1, name: "Подстанция № 1", at: [x, y] }
hospitals:                    # больницы — вымышленные; профили — из перечня профилей
  - { id: hosp.1, name: "Городская больница № 1", at: [x, y], profiles: [profile.stroke, profile.cardio, profile.general] }
```

Точка `at` привязывается к ближайшему доезжаемому узлу графа при сборке; валидатор проверяет, что до каждой больницы
можно доехать от каждой подстанции.

## 2. Состояние смены (`src/engine/types.ts`)

| Сущность | Поля | Кто видит |
|---|---|---|
| `Shift` | `t` (секунды от начала), зерно и ветки, `line`, `calls`, `crews`, очередь событий, журнал | движок |
| `Ring` | когда позвонил, кто звонит, к какому больному, адрес, повод | экран: время ожидания и повод |
| `Call` | заданные вопросы с ответами и временем, форма, нужная бригада, бригада, больница, времена: принят, решён, бригада выехала, на месте, уехала, в больнице | экран — всё, кроме правды о больном |
| `Patient` | болезнь, признаки с причинами, начало, возраст — **правда** | только движок и разбор закрытой смены |
| `Crew` | вид, подстанция, состояние, вызов, путь (откуда, куда, когда выехала, когда будет) | экран |
| `Outcome` | доезд против окна, бригада, профиль больницы — по правде | разбор |

Положение бригады в пути не хранится: экран считает его по пути и времени каждый кадр.

## 3. Сохранение (`src/state/`)

| Ключ | Что | Формат |
|---|---|---|
| `shift.current` | идущая смена | `{ schema, setup, seed, commands: [{ t, cmd }] }` — переигрывается движком |
| `shift.history` | законченные смены | итог, зерно и команды — разбор строится заново |
| `settings` | настройки | автопауза, скорость, «Меньше движения», вибрация, размер текста |
| `progress` | пройденные смены | какие смены открыты — без дат и серий |
