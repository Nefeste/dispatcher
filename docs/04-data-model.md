# Данные

Что лежит в содержании, в состоянии смены и в сохранении. Как это устроено в коде — [`02-architecture.md`](02-architecture.md),
откуда факты — [`09-content.md`](09-content.md).

## 1. Содержание (`content/`)

YAML, одна запись — один файл, идентификатор — из пути, вечный
([правило устава](https://github.com/Nefeste/gornitsa/blob/main/docs/05-rules.md#код)). Сборка —
`tools/content/build.ts` → `src/content/generated/` (не в git), как в «Анамнезе».

| Папка | Запись | Что в ней |
|---|---|---|
| `med/` | копии «Анамнеза» | болезни (`cond.*`), признаки, факторы риска, профессии, правила — байт в байт; `select.yaml` — какие болезни берём; `anamnez.json` — собранное подмножество; `FROM.yaml` — коммит «Анамнеза», SHA-256 ([`02-architecture.md`](02-architecture.md), §4) |
| `phone/findings/` | признак по телефону | заметит ли его звонящий каждого вида сам; его слова от себя и о другом; повод экстренной формы (388н, п. 11) |
| `phone/conditions/` | болезнь по телефону | доля среди вызовов, форма вызова, профиль больницы, доля госпитализаций, время на месте, доля с улицы, минут до звонка, окно |
| `reasons/` | повод | первые слова звонящего («упал{|а}, встать не может»): по каким признакам, по порядку, и сколько знающих с него начнут |
| `questions/` | вопрос диспетчера | группа, слова, цена в игровых секундах, кто знает ответ; какие признаки открывает или какие сведения: возраст, когда началось, как пройти, «что ещё» |
| `callers/` | звонящий | кем приходится больному, откуда звонит (дом, улица), доля, при каких признаках больной сам не позвонит, «не знаю» |
| `crews/` | вид бригады | состав, что умеет, с какими поводами её посылают |
| `cities/` | город | файл карты, район смены, подстанции, больницы с профилями |
| `shifts/` | смена | город, район, начало и длина, бригады по подстанциям, поток, учебные звонки |
| `roads.yaml` | дороги | скорость по классу дороги и множитель по часу суток — числа баланса |
| `flow.yaml` | поток | звонков в час по часу суток — число баланса, «оценка» |

Шаблоны слов: `{м|ж}` — по полу больного, `{^м|ж}` — по полу звонящего, `{who}` и `{Who}` — кто больной звонящему
(«отец», «соседка», «мужчина»). Полосы `tell` — полосы «Анамнеза» (`always` — 95 %, `usually` — 75 %, `often` — 50 %,
`sometimes` — 25 %, `rarely` — 8 %, `very_rarely` — 2 %, `never`) и своя `sure` — 100 %: свой возраст и адрес знают
наверняка. Доли и полосы — оценка (`estimate: true`), их подбирает «виртуальный диспетчер». Проценты — целые.

### Признак по телефону — `phone/findings/<id>.yaml`

```yaml
# идентификатор — из пути, тот же, что в content/med/: phone/findings/sym.chest_pain_pressing.yaml
tell: { self: always, relative: usually, neighbour: often, bystander: rarely }   # заметит ли сам, без вопроса
says:
  present:
    self: ["Давит за грудиной, как камень положили"]
    other: ["Говорит, давит за грудиной"]
threat: "388n, п. 11 «д»"     # повод экстренной формы — пункт и буква; нет — не повод
estimate: true
sources: ["anamnez", "388n, п. 11 «д»"]
notes: "…"                    # прочтение, если буква не названа прямо
review: draft
```

### Болезнь по телефону — `phone/conditions/<id>.yaml`

```yaml
# phone/conditions/cond.stroke_ischemic.yaml
weight: 8                 # доля среди вызовов смены, вес
form: emergency           # по правде; признак угрозы у больного делает форму экстренной всегда
hospital: stroke          # профиль больницы: stroke, cardio, trauma, neuro, uro, infect, general
transport: 100            # % тех, кого везут
scene: [15, 25]           # минут на месте
street: 15                # % вызовов не из дома
onset: [[30, 30], [90, 30], [240, 25], [720, 15]]   # минут от начала до звонка: [до, вес]
window: { minutes: 270, from: onset, source: "cr-814, 3.1.2.1.1" }   # от onset, call или crew; when — по параметрам болезни
# у состояний, где источник говорит, что без помощи в срок оно убивает (срез С3), — например, у анафилаксии:
# fatal: { late: 10, chance: 60, source: "cr-263, 1.6" }   # минут опоздания против нормы доезда, %; when — как у окна
# бригада на месте просит реанимационную (срез С4) — при параметрах болезни, по источнику о специальном методе:
# resus: { when: { type: [stemi], spo2_below90: [yes] }, source: "cr-157, 3.4.1.1" }
estimate: true
sources: ["388n, п. 11, вводная часть", "928n, пп. 17–18", "cr-814, разд. 6", "cr-814, 3.1.2.1.1"]
review: draft
```

### Вопрос — `questions/<id>.yaml`, звонящий — `callers/<id>.yaml`, повод — `reasons/<id>.yaml`

```yaml
# questions/breathing.yaml → q.breathing
group: vital              # who, vital, what, see, history, place
rank: 3
text: Как дышит?
label: Дыхание            # поле карточки вызова
cost: 15                  # игровых секунд
tell: { self: always, relative: usually, neighbour: usually, bystander: often }   # знает ли, о чём вопрос
opens: [sign.stridor, sym.dyspnea, sym.wheezing]   # называет первые два, что есть
none: { self: ["Дышу нормально"], other: ["Дышит ровно"] }   # знает, и ничего из них нет
# или about: age | onset | place | more — сведения вместо признаков, со своими словами (answer, years, bands, place)
```

Ответ: знает, о чём вопрос, — называет то, что есть, или говорит «нет»; не знает — называет только то, что заметил сам,
иначе «не знаю». Звонящий не врёт. Звонящий (`callers/`): `self`, откуда звонит (`at`), доля (`weight`), кем
приходится (`relations` — его слово и пол, слово о больном, для какого пола и возраста больного, картинка для сцены —
одна или своя для мужчины и женщины `{ m, f }`, из `assets/scenes/callers.json`),
при каких признаках больной сам не позвонит (`cannot`), «не знаю», «больше ничего» и первые слова повторного звонка
(`again`). Повод (`reasons/`): порядок (`rank`), признаки
(`when`), сколько знающих с него начнут (`say`, %), слова; один повод без признаков — смутное «плохо», на всякий случай.

### Город — `cities/<id>.yaml`

```yaml
# идентификатор — из пути: cities/proto.yaml → city.proto
map: nn-center               # src/map/generated/nn-center.ts, паспорт assets/map/nn-center.json
bases:                        # подстанции — вымышленные имена и места
  - { id: base.south, name: "Подстанция «Юг»", at: [8600, 12600] }
hospitals:                    # больницы — вымышленные; профили — из перечня профилей
  - { id: hosp.61, name: "Городская больница № 61", at: [9600, 14400], profiles: [stroke, cardio, neuro, uro, general] }
```

Точка `at` — единицы карты (0,5 м от северо-западного угла района, x — на восток, y — на юг). Сборка привязывает её к
ближайшему узлу дорог (не дальше 300 м) и проверяет:
- от каждой подстанции доезжают до каждой больницы и обратно;
- имя не совпадает с настоящим учреждением района из паспорта карты (`institutionsInArea`, без регистра, пробелов и
  знака номера) — ADR [0004](adr/0004-osm-map.md).

### Смена — `shifts/<id>.yaml`

```yaml
city: city.proto
start: 61200      # начало, секунды от полуночи (17:00)
length: 7200      # длина, секунды
season: autumn    # время года — от него болезни «Анамнеза»
crews:            # бригады по подстанциям; вид — запись crews/
  - { id: crew.3, kind: crew.resus, base: base.south }
script:           # учебные звонки до потока: когда (секунды), что, кто, откуда, тяжесть и первые слова
  - { at: 20, condition: cond.hypoglycemia, caller: caller.relative, where: home, params: { severity: severe }, first: clear }
```

Учебный звонок — случай без редкостей: у болезни есть свой признак, о котором знает телефон, а у экстренной — свой
признак угрозы (смена перебирает зёрна, пока так не выйдет). `params` — параметры болезни «Анамнеза» (сборка сверяет
имя и значение с записью болезни). `first: clear` — звонящий знает главные признаки и начинает с повода, который
называет один из них; `vague` — начинает со смутного «плохо» (часть П8, [`02-architecture.md`](02-architecture.md), §11). Поток — `flow.yaml`: `hours: [{ from, perHour }]`; первый
звонок потока — после последнего учебного.

### Вид бригады — `crews/<id>.yaml` и дороги — `roads.yaml`

Вид бригады: имя, класс машины (A, B или C — 388н, прил. 2), источники, `review: draft`. Дороги: скорость машины скорой
по классу дороги, км/ч, и множитель часа суток, % — числа баланса с пометкой «оценка» (`estimate: true`).

## 2. Состояние смены (`src/engine/shift.ts`)

| Сущность | Поля | Кто видит |
|---|---|---|
| `Shift` | `t` (мс от начала), зерно, `rev`, сколько вызовов родилось, следующий учебный звонок и звонок потока, `rings`, `calls`, `crews`, открытый разговор, извещения (`notices`), `over` | движок; экран — через виды |
| `Ring` | звонок на линии: вызов, когда позвонил, повторный ли, «перезвонил» (долго ждал на линии), звонят ли после отказа в выезде (`refused`, срез С3) | экран: сколько на линии |
| `CallRec` | правда вызова (`truth`: больной, звонящий, что он знает), адрес — узел дорог; состояние (звонок, разговор, ждёт, бригада едет, на месте, доклад, везут, в больнице, готово); первые слова, заданные вопросы со словами и временем, что узнали о признаках, возраст, когда началось; форма, бригада, больница; отметки времени — как в карте вызова (форма 110/у, `942` в [`09-content.md`](09-content.md)): поступление, приём, решение, передача бригаде, прибытие, доклад, начало транспортировки, прибытие в стационар, окончание; время на месте и везут ли — броски при звонке; повторные звонки; снятые бригады; для разбора — решения о форме с тем, что было слышно в ту минуту (`decisions`), что узнали из каждого ответа (`asked[].learned`), экстренные, которые ждали, когда этот неотложный получил бригаду (`bypassed`); умер ли больной до приезда бригады (`died`, срез С3: решает движок при прибытии по записи `fatal` — бригада видит это на месте) и когда позвонят после отказа в выезде (`callbackAt`); когда бригада на месте попросит реанимационную (`askAt`) и что было с просьбой (`second`: кто и когда просил, ответ — послали, «пусть везут сами», не ответили, была ли свободная реанимационная, какая приехала и когда; срез С4); когда бригада начала помогать (`inAt`: вошла в подъезд, нашла адрес); какая просьба не про медицину случится (`plan` — бросок при звонке: подъезд, адрес, второй пострадавший; экран его не видит), когда бригада попросит про второго (`snagAt`) и что было с просьбой (`snag`: вид, кто и когда просил, ответ — перезвонили, послали, «ждите» / «сами», не ответили; когда бригада снова за делом, сколько ждали бы сами, была ли свободная бригада, экстренные, ждавшие бригаду, бригада ко второму, верный адрес; срез С4, вторая половина); передали ли в поликлинику (`clinic`: когда, когда её врач у больного, с чем вернулся вызов — угроза, нужна больница или ничего; срез С5) | экран — через `callView` и `pultView`, без правды о больном; смерть — только как доклад бригады по рации |
| `Crew` | вид, подстанция, состояние (с 0.13.0 и «пополняет укладку»), вызов, путь (узлы, рёбра, время до каждого узла, когда выехала), до какого момента стоит, на сколько вызовов осталось укладки (`kit`) | экран |
| `Lineup` | что смене дала станция: её бригады сверх записи смены (номер, вид, подстанция), укладки бригад с прошлой смены (`lineup`, срез, часть С2) и бригады, обученные до реанимационных (`trained`, С4) | движок, сохранение |
| `Trail` | пройденный путь бригады: бригада, состояние в пути, узлы и рёбра; путь, сменённый в дороге, обрезан там, где бригада была (`trail`, часть П8) | снимок смены |
| `Notice` | что случилось и когда: звонок, повторный звонок, «на месте», доклад, повезли без ответа, освободилась, укладка пустая — едет пополнять, на подстанции, развернули, конец смены | экран: рация и автопауза |
| `CallReview` | исход по правде (доезд против нормы, окно, та ли больница, смерть до приезда) и его ступень (`tier`: вовремя, с опозданием, не дождался помощи — срез С3), ошибки по известному с ценой в минутах — `src/engine/review.ts`, строится из смены, не хранится | разбор закрытой смены (`reviewView`) |

Положение бригады в пути не хранится: экран считает его по пути и времени каждый кадр.

## 3. Сохранение (`src/state/`)

| Ключ | Что | Формат |
|---|---|---|
| `shift.current` | идущая смена | `{ v, setup, seed, t, log: [{ t, cmd }], played, lineup }` — переигрывается движком (`replay`) с тем, что дала станция (`lineup`), часы доводятся до `t`; `played` — время игры, мс настоящего времени; смена кончилась — ключ стирается. `v` = 2 с 0.13.0: смена 0.12.0 по новым правилам переигралась бы в другую — она не продолжается; `v` = 3 с 0.14.0 — то же для смерти до приезда и повторного звонка после отказа; `v` = 4 с 0.15.0 — для просьбы о реанимационной; `v` = 5 с 0.16.0 — у ночной смены 4 другой поток; `v` = 6 с 0.17.0 — просьбы на месте не про медицину и команда `snag`; `v` = 7 с 0.19.0 — поликлиника, команда `pass` |
| `shift.history` | законченные смены | итог, зерно и команды — разбор строится заново |
| `settings` | настройки | `{ autopause, sound, haptics, lessMotion?, softOutcome }`; нет `lessMotion` — как в системе телефона; `softOutcome` — «Мягкий исход» (срез С3), нет — выключен; размер текста — с 1.0 |
| `progress` | лучший итог | `{ best: { [смена]: { emergency, inNorm, urgentMedian, accepted } } }` — без дат и серий; какие смены открыты — с «Первой неделей» |
| `station` | станция недели (срез, части С2–С3) | `{ fund, extra: [{ id, kind, base }], kits: { [бригада]: вызовов }, journal: [{ kind, amount, after, crew?, base? }], letter, done: [смена], decided }`; в письме с 0.14.0 — смерти до приезда и служебные проверки (номера вызовов), в журнале — строки `inquiry`; с 0.15.0 — `trained` (бригады, обученные до реанимационных) и строки журнала `resus` — фонд в рублях, бригады станции, неполные укладки (нет записи — полная), журнал фонда, письмо после последней смены, смены, итог которых станция приняла (повтор не меняет), решений в этом перерыве; чужая форма — станция с начала недели |
| `week` | журнал недели (срез, часть С8) | `{ map, edges, shifts: [{ shift, emergency, inNorm, deaths, paths }] }` — по строке на смену, принятую станцией (повтор не меняет, как станцию): числа итога и рёбра карты, по которым ехали бригады, — битовой маской шестнадцатеричной строкой (`paths`, 768 знаков на 3072 ребра района); `map` и `edges` — по какой карте записаны пути (другая — пути не рисуются). Из него — «Итог недели» и снимок недели. «Неделя заново» стирает его и станцию; `progress` остаётся |

Изменился смысл поля — версия схемы, шаг миграции и новый образец в `tools/test/fixtures/saves/`
([ADR 0004 устава](https://github.com/Nefeste/gornitsa/blob/main/adr/0004-pure-engine-snapshots.md)).
