# Проверки

Что прогонять до того, как сказать «готово» и до каждого push. CI на PR прогоняет первые три
([`05-process.md`](05-process.md)); остальное — агент сам.

| Что | Команда | Когда |
|---|---|---|
| Содержание | `npm run content` — `content/` → `src/content/generated/` (не в git); его же зовут `typecheck` и `test` | всегда |
| Типы | `npm run typecheck` | всегда |
| Линтер, без предупреждений; правила чистоты движка | `npm run lint` | всегда |
| Тесты | `bun test tools/test` | всегда |
| Веб-сборка | `npm run export:web` | изменение интерфейса |
| Сценарий в браузере | `NODE_PATH=/opt/node22/lib/node_modules bun tools/e2e/browser.ts` | изменение интерфейса |

## Сценарий в браузере (`tools/e2e/browser.ts`)

Веб-сборка из `dist-web/` с `?pace=20` (часы смены в 20 раз быстрее ×1), Chromium без окна (WebGL — программный
SwiftShader), настоящие нажатия. Сквозной путь спецификации (§3): первый экран → настройки → «Начать смену» → загрузка →
вставка «начало смены» → ввод поверх карты → пульт (сдвиг карты мышью; первый звонок ставит паузу) → учебный звонок 1
по подсказкам (вопрос, форма, бригада) → вставка «бригада выезжает» → вся смена до конца: звонки, ожидание, бригады с
пульта, доклады и больницы → итог (время игры, лучший итог) → снимок смены (файл сохраняется в `tools/e2e/out/`) →
разбор (главная ошибка, вызов по известному и по правде) → рабочее место (поворот взгляда мышью) → «Об игре» → назад;
снимки — `tools/e2e/out/`. Ошибка в консоли — провал.
