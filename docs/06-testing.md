# Проверки

Что прогонять до того, как сказать «готово» и до каждого push. CI на PR прогоняет первые три
([`05-process.md`](05-process.md)); остальное — агент сам.

| Что | Команда | Когда |
|---|---|---|
| Типы | `npm run typecheck` | всегда |
| Линтер, без предупреждений; правила чистоты движка | `npm run lint` | всегда |
| Тесты | `bun test tools/test` | всегда |
| Веб-сборка | `npm run export:web` | изменение интерфейса |
| Сценарий в браузере | `NODE_PATH=/opt/node22/lib/node_modules bun tools/e2e/browser.ts` | изменение интерфейса |

## Тесты (`tools/test/`)

| Файл | Что проверяет |
|---|---|
| `i18n.test.ts` | кириллица в коде — только в `src/i18n/` и в комментариях |
| `version.test.ts` | номер версии одинаков во всех файлах, у неё есть раздел в `README.md` |
| `settings.test.ts` | разбор настроек: мусор — по умолчанию, «меньше движения» — как в системе |
| `docs.test.ts` | `STATUS.md` не длиннее 30 строк; относительные ссылки ведут к файлам; ADR — в оглавлении |
| `workflows.test.ts` | проверки PR на каждом PR, имя проверки — то, что ждёт автослияние; `ubuntu-24.04` |

Дальше, по частям прототипа, — золотой тест смены, дороги против перебора, сборка карты байт в байт, валидатор
содержания, «виртуальный диспетчер» ([`02-architecture.md`](02-architecture.md), §8).
