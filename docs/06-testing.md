# Проверки

Что прогонять до того, как сказать «готово» и до каждого push. CI на PR прогоняет первые три
([`05-process.md`](05-process.md)); остальное — агент сам.

| Что | Команда | Когда |
|---|---|---|
| Типы | `npm run typecheck` | всегда |
| Линтер, без предупреждений; правила чистоты движка | `npm run lint` | всегда |
| Тесты | `bun test tools/test` | всегда |
| Веб-сборка | `npm run export:web` | изменение интерфейса |
| Сценарий в браузере | `NODE_PATH=/opt/node22/lib/node_modules bun tools/e2e/browser.ts` | изменение интерфейса |

## Тесты (`tools/test/`)

| Файл | Что проверяет |
|---|---|
| `i18n.test.ts` | кириллица в коде — только в `src/i18n/` и в комментариях |
| `version.test.ts` | номер версии одинаков во всех файлах, у неё есть раздел в `README.md` |
| `settings.test.ts` | разбор настроек: мусор — по умолчанию, «меньше движения» — как в системе |
| `docs.test.ts` | `STATUS.md` не длиннее 30 строк; относительные ссылки ведут к файлам; ADR — в оглавлении |
| `workflows.test.ts` | проверки PR на каждом PR, имя проверки — то, что ждёт автослияние; `ubuntu-24.04` |
| `map.test.ts` | паспорт карты сходится с файлом в сборке; чтение и запись — байт в байт; формы рёбер начинаются и кончаются в узлах; если выгрузка лежит в `map-src/`, сборка из неё повторяет файл байт в байт |
| `desk.test.ts` | паспорт модели рабочего места сходится с файлами; области палитры — те же, что у скрипта Blender; треугольники целы; у каждого экрана, который рисует игра, есть место в модели |
| `skia.test.ts` | ловушки нативной Skia из пробы 3D: картинка без начала записи, `Data.fromBytes` со смещением |
| `scenes.test.ts` | паспорта кадров сцен, звонящих и ролика сходятся с файлами; раскладка пульта и разговора — на экранах 360 × 640 … 412 × 915: всё на экране, касания не наезжают, вопросы и решение — в нижней половине; матрица экранчиков переводит углы в углы |
| `road.test.ts` | поиск пути совпадает с перебором (Флойд — Уоршелл) на 200 малых графах, вперёд и назад; время ребра — целое; район связен целиком; обратный поиск по району — до 40 мс в Bun |

Дальше, по частям прототипа, — золотой тест смены, валидатор содержания, «виртуальный диспетчер» ([`02-architecture.md`](02-architecture.md), §8).

## Сценарий в браузере (`tools/e2e/browser.ts`)

Веб-сборка из `dist-web/`, Chromium без окна (WebGL — программный SwiftShader), настоящие нажатия. Сейчас: первый экран → пульт (сдвиг карты мышью, пауза, телефон) → разговор (два вопроса, решение) → видеовставка → пульт → рабочее место (поворот взгляда мышью) → «Об игре» → назад; снимки —
`tools/e2e/out/`. Ошибка в консоли — провал. С каждой частью прототипа сценарий растёт до сквозного пути
спецификации (§3).
