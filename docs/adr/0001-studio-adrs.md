# 0001. Какие ADR студии действуют здесь и как

Общие решения — в уставе, [`adr/`](https://github.com/Nefeste/gornitsa/tree/main/adr). Здесь они не пересказываются,
только как применены в «Диспетчере 03».

| ADR студии | Здесь |
|---|---|
| 0002 — код копируется с пометкой источника | медицинская модель и сборка содержания — из «Анамнеза»; поток вызовов по часам и «виртуальный игрок» — по образцу «Больницы»; диалог, тексты, журнал сбоев, хранилище и настройки — из «Вотчины» ([`02-architecture.md`](../02-architecture.md), «Что берём у соседей») |
| 0003, 0019 — Expo, нативные папки генерируются, CI на PR, APK только на тег | Expo SDK 57, как у остальных игр; CI — с первым кодом |
| 0004 — чистый детерминированный движок, снимки | `src/engine/`: целые секунды, зерно, `apply` и `advance`; сохранение смены — зерно и список команд, переигрываемый движком |
| 0005 — без сети по умолчанию | вся игра работает без сети, карта лежит в сборке; сервера нет |
| 0006 — постоянный идентификатор и ключ | предложение — `games.gornitsa.dispetcher`; утверждает владелец до первой сборки, которую кто-то поставит |
| 0008 — данные минимум | игра ничего не отправляет; своя статистика — только по решению владельца, до выпуска |
| 0009 — деньги не покупают преимущество | в прототипе денег нет; модель денег — вопрос владельцу до выпуска ([`08-game-design.md`](../08-game-design.md), «Деньги») |
| 0010 — без давления | разговор пошаговый, игровое время, пауза в любой момент (ADR [0003](0003-turn-based-call.md)); ни энергии, ни серий |
| 0011 — честная игра | разбор судит по тому, что было известно (ADR [0005](0005-judge-by-known.md)); случайность вызовов — из записанного зерна |
| 0012 — контент из названных источников | медицина — по правилам «Анамнеза» (ADR [0002](0002-med-model-from-anamnez.md)); карта — OpenStreetMap (ADR [0004](0004-osm-map.md)) |
| 0017 — видимость | отступление: репозиторий открыт до 1.0.0 по решению владельца 19.11.2026 (ADR [0008](0008-open-until-1.0.md)) |
| 0018 — права по классам | пути владельца — в [`.github/CODEOWNERS`](../../.github/CODEOWNERS) |
| 0022 — набор `gornitsa-kit` | CI, подпись, проверки APK и загрузка в RuStore — из набора; RuStore Pay — оттуда же, если будут покупки |
| 0023 — графика | цель кадра — 60 к/с на телефоне владельца; лист стиля с тремя эталонными кадрами — до первой картинки карты; «Меньше движения» в настройках |
| 0024 — 3D на телефоне | 3D нет: карта — плоская, своим отрисовщиком на Skia |
