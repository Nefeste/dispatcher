# 0004. Настоящие улицы из OpenStreetMap, своя карта в сборке; станции и больницы вымышлены

**Решили.**

- **Улицы, реки, мосты и железные дороги — из OpenStreetMap.** Выгрузку района превращает в файл игры скрипт
  `tools/map/build.ts`. Это локальная команда, не CI. Файл `assets/map/<город>.bin` коммитится с паспортом: адрес
  выгрузки и её дата, SHA-256 входа и выхода, рамка, лицензия ([`../02-architecture.md`](../02-architecture.md), §5).
- **Карта лежит в игре** и работает без сети. Телефон ничего не скачивает и не спрашивает разрешения на геолокацию.
- **Рисуем сами**, на Skia, по слоям из файла. Ни Яндекс Карт, ни других карт по сети. Это то же решение, что владелец
  принял для «Города»: OpenStreetMap со своим отрисовщиком.
- **Подстанции и больницы вымышлены**: свои имена и места, не совпадающие с настоящими учреждениями района
  ([`../09-content.md`](../09-content.md), §3). Как и в «Городе»: настоящие улицы, вымышленные организации. Они лежат в
  записях содержания `content/cities/`, **отдельно от файла карты**: в файл OSM чужие данные не подмешиваются.
- **Лицензия ODbL 1.0 выполняется так** (по руководствам OSMF, источники — [`../09-content.md`](../09-content.md), §4):
  - **Указание источника.** На карте — строка «© участники OpenStreetMap». В «Об игре» — полностью: данные карты
    © участники OpenStreetMap, лицензия ODbL, ссылка `openstreetmap.org/copyright`. В руководстве по указанию источника
    для игр подходят экран игры, титры и меню. Поиск пути тоже работает на данных OSM, это указание его покрывает.
  - **Файл карты — производная база данных** по ODbL: граф большого города — «существенная» часть данных. Он
    распространяется под ODbL. Рядом лежит текст лицензии или ссылка на неё, внутри файла — указание на OSM. Шифровать
    файл нельзя (ODbL 4.7).
  - **Как получить базу.** Получатель игры должен иметь способ получить саму базу или способ её собрать (ODbL 4.6). Это
    скрипт `tools/map/build.ts` и адрес выгрузки в паспорте. Пока репозиторий открыт (ADR [0008](0008-open-until-1.0.md)),
    они лежат в нём; если его закроют, файлы карт и скрипт выкладываются на страницу игры на сайте gornitsa.games.

**Почему.**

- Карточка игры обещает настоящие улицы. Свой город из головы не даст ни мостов, ни узких мест, ни узнавания.
- OpenStreetMap — единственные открытые данные дорог, которые можно положить в игру без платы и без сети.
- Вымышленные учреждения: игра не должна говорить ничего о работе настоящей станции скорой или больницы. Отдельный
  набор `content/cities/` не попадает под share-alike карты (руководство OSMF о сборных базах).

**Платим.**

- **Город — по одному.** Каждый новый город — сборка, проверка доезжаемости, расстановка подстанций и больниц руками.
- **Ошибки данных OSM** — тупики, лишние односторонние, нет моста — переходят в игру. Валидатор карты ловит
  недоезжаемые места, остальное ловит игра владельца.
- **Обязательства ODbL** живут, пока игра в магазине: строка источника, текст лицензии, доступ к файлу карты или к
  способу его собрать. Закрытый репозиторий требует публиковать файлы карт отдельно.
- **Где кончается «тривиальное преобразование»,** у OSMF записано противоречиво: страница руководства числится и
  предложением, и одобренным документом. Поэтому файл карты распространяется под ODbL — по более строгому прочтению.
  Это не юридическое заключение: перед выпуском формулировку стоит проверить юристу.
