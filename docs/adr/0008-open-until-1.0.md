# 0008. Репозиторий открыт до 1.0.0

**Решили.** «Диспетчер 03» отступает от ADR студии
[0017](https://github.com/Nefeste/gornitsa/blob/main/adr/0017-repo-visibility.md): по нему новый репозиторий студии
закрыт по умолчанию. Здесь репозиторий остаётся открытым, пока идёт активная разработка, — вплоть до версии 1.0.0.
Решение владельца 19.11.2026: «репозиторий открытый при активной разработке вплоть до версии 1.0.0». Устав разрешает
ADR проекта отступать от ADR студии с разрешения владельца (`docs/04-process.md` устава, «ADR»). Так же сделано в
«Анамнезе» (его ADR 0018).

**Почему.**

- Минуты GitHub Actions у открытого репозитория бесплатны: проверки на PR и сборка по тегу не тратят общие 2000 минут
  закрытых репозиториев студии.
- Наборы правил, защита веток и `CODEOWNERS` работают на бесплатном тарифе GitHub только в открытом репозитории (ADR
  студии 0017, «Платим»).
- Лицензия карты ODbL требует дать получателю игры способ получить базу карты или собрать её (ADR
  [0004](0004-osm-map.md)). В открытом репозитории это скрипт `tools/map/build.ts` и паспорт карты, без отдельной
  выкладки на сайт.
- Сайт забирает страницу игры (`store/site/`) без токена (ADR студии 0015).

**Платим.**

- Виден весь репозиторий с историей: код до выпуска, медицинские записи — черновики (`review: draft`), материалы
  магазина. Паролей, ключей, денежных расчётов и личных данных в нём нет и не будет, как в любом открытом репозитории
  студии. Ключи подписи живут только в секретах GitHub.
- Внутренние подробности студии (очередь решений, управа) сюда не пишутся: только то, что можно показать.
- Проект отступает от правила студии. При переходе между проектами это нужно знать.

**Когда пересмотреть.** Перед выпуском 1.0.0: закрыть репозиторий по ADR студии 0017 или оставить открытым новым
решением владельца. Если закрыть, файлы карт и скрипт их сборки выкладываются на страницу игры на сайте (ADR 0004).
