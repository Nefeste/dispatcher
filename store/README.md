## Предзаказ в RuStore — по шагам (владелец)

1. Консоль RuStore → «Создать приложение» → способ публикации «Предзаказ». Пакет — `games.gornitsa.dispatcher`
   (вечный, ADR устава 0006). APK для предзаказа не нужен.
2. Название, краткое и полное описание, «Что нового», ключевые слова и категория — из [`listing.ru.md`](listing.ru.md).
3. Значок — `graphics/icon-512.png`, баннер — `graphics/feature-1024x500.png`, снимки — список ниже, по порядку.
4. Частые вопросы — из [`faq.ru.md`](faq.ru.md).
5. Возрастная категория, цена и политика — ещё не решены (вопрос денег — [#46](https://github.com/Nefeste/dispatcher/issues/46),
   возраст — до выпуска). Если консоль требует их уже для предзаказа: игра без денег и рекламы, без сети и данных
   игрока; возраст — тот, что выйдет по анкете RuStore (у похожих игр — 12+: медицинская тема без сцен насилия).
   Ответ запишем в журнал и в `forms.md`, когда он будет.
6. Ссылку на карточку пришлите агенту: она встанет на страницу сайта кнопкой «Предзаказ в RuStore».

## Снимки для карточки

1. `01-call.png` — разговор: звонит сын, вопросы по разделам, срочность внизу
2. `02-crews.png` — экстренная — кого послать: бригады по времени доезда
3. `03-map.png` — пульт: карта Нижнего Новгорода, кого послать на ждущий вызов, адрес вызова
4. `04-report.png` — разбор смены: главная ошибка и её цена
5. `05-call-review.png` — разбор вызова: разговор и решение по услышанному
6. `06-station.png` — станция между сменами: фонд, укладка, закупки
7. `07-week.png` — «Первая неделя»: семь смен и лучший итог каждой
8. `08-desk.png` — рабочее место диспетчера

Кадры сняты сценарием браузера (`tools/e2e/browser.ts`) в окне 432 × 768 при плотности 2,5 — ровно 1080 × 1920, 9 : 16.
Кадр 12 (пульт с бригадами) зависит от времени сценария и выходит разным, поэтому третий снимок — кадр «pult-waiting». Кадры ищутся по имени без номера: номера сдвигаются. Кадр 23 сценария (письмо на станции) не годится: текст письма в узком окне наезжает на табель.
